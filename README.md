# homebrew-tap

Official Homebrew tap for Velos developer tools.

## Installation

Add this tap and install the `velos` CLI compiler and orchestrator:

```bash
brew install velos-io/tap/velos
```

Or tap explicitly:

```bash
brew tap velos-io/tap
brew install velos
```

## Available Formulas

| Formula | Description |
|---|---|
| `velos` | High-performance deployment compiler and orchestrator for Velos specifications |
